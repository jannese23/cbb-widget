# CBB Desktop Widget Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a macOS extra-large desktop widget showing UConn, the big college basketball games and scores that matter around UConn, and 2026–27 student ticket claims.

**Architecture:** All logic lives in a local Swift package (`CBBCore`: models, ESPN decoding, selection rules, ticket claims, board building, fetching and caching), so it can be TDD'd with `swift test`. The SwiftUI view lives in `CBBUI` and is rendered to a PNG by a small `cbb-render` CLI for visual checks. A thin Xcode project (generated by XcodeGen) wraps it in a host app and a WidgetKit extension.

**Tech Stack:** Swift 6.4 / Swift Testing, SwiftUI, WidgetKit, Xcode 27.2, XcodeGen (Homebrew), ESPN public site API.

**Spec:** `docs/superpowers/specs/2026-11-12-cbb-widget-design.md` (read it first; the plan doesn't repeat its rules verbatim except where values are pinned)

## Global Constraints

- macOS 26.0 deployment target; Xcode 27.2; widget family `systemExtraLarge` only.
- Repo `~/Dev/Projects/cbb-widget`, remote `github.com/jannese23/cbb-widget` (private). Commit after every task; push at the end of each task.
- Signing: team `A4U8TCFTCZ` (Apple Development: jackson.annese@icloud.com), automatic signing. Bundle IDs `com.jannese.cbb` (app) and `com.jannese.cbb.widget` (extension).
- Both targets sandboxed with `com.apple.security.network.client`. No App Group: the app and the widget each fetch and cache on their own.
- All day boundaries and ticket times use `TimeZone(identifier: "America/New_York")`; display uses the Mac's local time zone.
- ESPN `curatedRank.current == 99` means unranked → `rank == nil`.
- UConn team id `"41"` in both leagues. Big-name program ids: Duke 150, North Carolina 153, Kentucky 96, Kansas 2305, UCLA 26, Indiana 84, Michigan State 127, Villanova 222, Louisville 97, Syracuse 183, Arizona 12, Gonzaga 2250.
- Logos: `https://a.espncdn.com/i/teamlogos/ncaa/500-dark/{id}.png`. Widgets can't use `AsyncImage`; logos are downloaded during the fetch, resized, and cached on disk.
- No third-party Swift dependencies.
- Follow the `~/.claude/CLAUDE.md` file-safety rules: delete only files you created, by exact path.

## Review Focus

1. **ESPN dates without seconds** (`"2026-11-13T02:00Z"`): `ISO8601DateFormatter` rejects these by default; every game would silently vanish. → test in Task 1.
2. **Odd events** (TBD opponent, missing `score`/`curatedRank`/`venue`, postponed or canceled games): one bad event must not drop the whole day, and postponed/canceled games must never show as "Final" or count as results. → tests in Task 1 and Task 4.
3. **Network down or ESPN changed**: the widget keeps showing the last good data with "Updated h:mm"; on the very first run with no cache it shows a short "Couldn't load scores" message, never an empty glass box. → tests in Task 5, check in Task 7.
4. **Ticket boundaries and DST**: exactly 10:00 PM / 11:59 PM Eastern, including claims before and after the Nov 1 DST change; overlapping windows show both rows. → tests in Task 3.
5. **Late games crossing midnight Eastern**: a 10 PM tip still live at 12:30 AM must stay in Today (as live), not vanish or jump to Latest. → test in Task 4.

  ```swift
  public enum Caption: String, Codable, Sendable { case bothRanked = "Both ranked", upset = "Upset" }
  public enum Tier: Int, Comparable, Sendable { case uconn = 0, bothRanked, prominent, upsetInProgress, rankedVsUnranked, other }
  public enum BigGames {
      public static let uconnID = "41"
      public static let prominentProgramIDs: Set<String>   // the 12 ids in Global Constraints
      public static func isBothRanked(_ g: Game) -> Bool
      public static func isProminent(_ g: Game) -> Bool    // both teams in the set, ranks ignored

      public static func isUpsetInProgress(_ g: Game) -> Bool  // live, period >= 2, current leader would make it an upset
      public static func isBlowout(_ g: Game) -> Bool       // final, ranked beat unranked by >= 20 (builder's call, spec: "blowouts")
      public static func qualifiesForComingUp(_ g: Game) -> Bool  // UConn || bothRanked || prominent || (a top-10 vs an unranked)
      public static func qualifiesForScores(_ g: Game) -> Bool    // UConn || any ranked team || prominent
      public static func tier(_ g: Game) -> Tier
      public static func caption(_ g: Game) -> Caption?     // upset (final) wins over bothRanked; nil otherwise
      public static func comingUpOrder(_ a: Game, _ b: Game) -> Bool   // spec: UConn, bothRanked (lower rank sum), prominent, top-10 vs unranked; tie → earlier start
      public static func importanceOrder(_ a: Game, _ b: Game) -> Bool // tier, then lower rank sum / better best rank, then earlier start
  }
  ```

### Task 4: Board builder

**Files:** Create `Sources/CBBCore/BoardBuilder.swift`; Test `Tests/CBBCoreTests/BoardBuilderTests.swift`

**Interfaces:**
- Consumes: `Game`, `ESPNDecoder` (Task 1), `BigGames` (Task 2), `TicketSchedule`, `TicketRow` (Task 3).
- Produces:
  ```swift
  public struct BoardInputs: Codable, Sendable {
      public var menScoreboard: [Game]   // men's D1 scoreboards, ET days today-2 … today+7
      public var menSchedule: [Game]; public var menRecord: String?
      public var womenSchedule: [Game]; public var womenToday: [Game]   // women's scoreboard for today (live overlay)
  }
  public struct UConnSummary: Codable, Sendable { public let record: String?; public let rank: Int?; public let live: Game?; public let next: Game?; public let last: Game? }
  public struct Board: Codable, Sendable {
      public let now: Date; public let uconn: UConnSummary; public let women: Game?; public let tickets: [TicketRow]
      public let comingUp: [Game]; public let today: [Game]; public let latest: [Game]
  }
  public enum Slots { public static let rightColumn = 6; public static let latestMinimum = 2; public static let leftComingUp = 3 }
  public enum BoardBuilder { public static func build(_ inputs: BoardInputs, now: Date) -> Board }
  ```

Rules (values from the spec; "ET day" = calendar day in America/New_York):
- `uconn.live`: a `.live` UConn game from `menScoreboard`, else from `menSchedule`. `next`: earliest `.pre` UConn game in `menSchedule`. `last`: latest `.final` in `menSchedule`. `rank`: UConn's rank in the most recent of those games.
- `women`: live UConn game vs a ranked opponent (prefer `womenToday`) → next `.pre` vs ranked opponent within 7 days → latest `.final` vs ranked opponent within 3 days → nil.
- `tickets`: `TicketSchedule.rows(at: now)`.
- `today`: `menScoreboard` games that `qualifiesForScores`, and either start on today's ET day or are `.live`; excluding `.postponed`. If more than `rightColumn - min(latestMinimum, latestCandidates.count)`, keep the top by `importanceOrder`. Display order: live, then pre by start, then final by start.
- `latest`: `.final` games that `qualifiesForScores`, starting in the 2 ET days before today; ordered upsets, then bothRanked, then prominent, then the rest, with `isBlowout` games last; most recent first within a group. Fill the remaining right-column slots.
- `comingUp`: `.pre` games that `qualifiesForComingUp`, starting from tomorrow's ET day through today+7, excluding `uconn.next`'s id; sorted by `comingUpOrder`; take `leftComingUp - max(0, tickets.count - 1)`.
